## Installation

```git clone git@github.com:agencetwogether/commentable_assets.git```

```cd commentable_assets```

```composer install```

```php artisan migrate --seed```

```npm install```

```npm run build```

```php artisan serve```

Go to ```http://127.0.0.1:8000```, credentials are prefilled, 

1. Open database notification sidebar and see CSS issue.
2. Remove businesstillo directory from public/css and refresh page. Now notifications show with no issue.
